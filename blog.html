What I Learned from Building My First Database System

When my lecturer assigned a full database project for our Advanced Database course, I had no idea how deep the rabbit hole would go. We had to build a complete system — from ER diagrams to RBAC security to OLAP queries — and I learned more in those weeks than in most of the semester.

The biggest lesson? Naming things properly from day one. Once you have 20 tables with vague column names, it's too late. Every query becomes a guessing game.

If you're starting a database project, my advice: draw the ERD first, get it reviewed, then start coding. Don't skip the plan.
